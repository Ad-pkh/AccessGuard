# Company Module Skeleton

This module is intentionally left as a folder skeleton only.

## Folder Purpose

- `Application/DataTransferObjects`: application-layer data carriers.
- `Application/UseCases`: application actions.
- `Domain/Entities`: pure business entities.
- `Domain/Repositories`: repository contracts.
- `Http/Controllers`: HTTP entry points.
- `Http/Requests`: HTTP validation objects.
- `Infrastructure/Entities`: Eloquent models.
- `Infrastructure/Persistence/Eloquent/Repositories`: Eloquent repository implementations.
- `Providers`: module service providers and bindings.
- `config`: module configuration.
- `database/factories`: factories.
- `database/migrations`: schema migrations.
- `database/seeders`: seeders.
- `resources/assets`: front-end assets.
- `resources/views`: Blade views.
- `routes`: route files.
- `tests/Feature`: feature tests.
- `tests/Unit`: unit tests.
